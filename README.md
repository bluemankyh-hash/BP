# 혈압 관리 (BP)

저염식 · 러닝 · 체중으로 혈압을 낮추는 개인용 기록 앱입니다.

- **화면**: 이 저장소의 `index.html` (GitHub Pages로 공개)
- **데이터**: 구글 시트 + Apps Script (`apps-script/Code.gs`를 시트의 Apps Script에 붙여넣어 씁니다)
- 비밀 열쇠와 카카오 키는 코드에 없고, Apps Script의 스크립트 속성에만 저장됩니다.

## 기능
- 혈압 · 맥박 · 체중 · 러닝 기록, 최근 7일 비교, 추이 그래프
- 먹은 음식을 적으면 칼로리 · 나트륨 추정 (한국 음식 약 150가지 + 내 음식사전)
- GPS 러닝 기록 (거리 · 시간 · 페이스 · 칼로리), 자주 뛰는 코스 저장
- 주변 10km 저염 친화 식당 (카카오 장소 검색)
- 카카오톡 알림: 아침 8시 혈압, 저녁 8시 운동 확인, 월요일 주간 리포트

이 앱은 의료기기가 아니며 진단을 하지 않습니다.
